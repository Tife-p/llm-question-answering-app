# LLM Question Answering Application

A web-based Question Answering application that uses a Large Language Model (LLM) to generate responses to user questions.

The application allows users to interact with an AI-powered system through a simple web interface and receive generated responses in real time.

## Features

- Ask questions through a web-based interface
- Generate AI-powered responses using an LLM
- Simple and interactive user interface
- Command Line Interface (CLI) version included
- Flask-based backend

## Technologies Used

- Python
- Flask
- Large Language Models (LLMs)
- HTML
- CSS
