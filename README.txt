# LLM Question Answering Application

A web-based Question Answering application that uses a Large Language Model (LLM) to generate responses to user questions.

The application allows users to interact with an AI-powered system through a simple web interface and receive generated responses in real time.

## Features

- Ask questions through a web-based interface
- Generate AI-powered responses using an LLM
- Simple and interactive user interface
- Command Line Interface (CLI) version included
- Flask-based backend

## Technologies Used

- Python
- Flask
- Large Language Models (LLMs)
- HTML
- CSS

## Project Structure

```text
├── static/                 # CSS and other static files
├── templates/              # HTML templates
├── app.py                  # Flask application
├── LLM_QA_CLI.py           # Command Line Interface version
├── requirements.txt        # Project dependencies

## How to Run Locally

1. Clone the repository

bash
git clone https://github.com/Tife-p/llm-question-answering-app.git

2. Navigate into the project folder

bash
cd llm-question-answering-app

3. Install the required dependencies

bash
pip install -r requirements.txt

4. Configure your API key as required by the application.

5. Run the application

bash
python app.py
